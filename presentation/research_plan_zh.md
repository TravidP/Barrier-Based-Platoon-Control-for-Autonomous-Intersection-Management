# 研究计划：通行顺序与多冲突安全过滤

状态：研究提案，无已完成实验或安全证明。本文给出建议研究路线；参数是首轮实验设计默认值，不是已经验证的安全阈值。不实施控制器、不改写原论文。

## 1. 目标与贡献定位

研究对象是允许 V2X 或路侧协调的开放道路自动驾驶交叉口。目标是分析：在固定路径和加速度受限条件下，如何把一致的通行顺序与多冲突安全约束结合，同时保留平顺跟驰，并量化延误、停车及舒适性代价。

三个研究问题：

1. 全局排序、承诺保持与等待优先规则，能否减少反复让行和相互矛盾的局部优先级？
2. 哪些初始状态和控制边界支持持续可行的安全过滤？有限尺寸车辆的区域占用怎样进入约束？
3. 相同交通需求下，排序和安全过滤分别对安全、效率与舒适性产生什么影响？

潜在贡献是接口设计、可行性分析和实证边界。冲突图、CBF 和 QP 都是已有工具；在系统检索之前不宣称方法首创。不承诺无通信、不停车、全局无死锁、任意初态安全或串稳定性。

## 2. 第一阶段模型与接口

### 场景和信息

- Case A：南北两个相反方向的独立直行车道，与东向西单向直行车道相交。三个有向运动的冲突矩阵为 `[[0,0,1],[0,0,1],[1,1,0]]`。
- 固定路径、无变道、全部车辆受控。道路几何和车辆尺寸定义各路径的冲突区域入口与出口；不能把两个局部冲突压成一个无尺寸点。
- 采用单个路侧协调器，先使用同步、无误差状态和已知路线。所有结果明确适用此假设。通信延迟、丢包和状态误差属于后续敏感性实验。
- 不只保留每车道最近的一辆车：控制范围内车辆进入状态集，仍占据区域的车辆保留到车尾离开。后车可能影响已承诺车流，因此候选缩减需要单独验证。

### 建议接口

这些是后续控制器的概念接口，本次交付不新增可执行 API。

| 模块 | 输入 | 输出与不变量 |
|---|---|---|
| 状态与几何 | ID、时间戳、路径位置、速度、路线、车长车宽 | 各区域剩余距离及占用状态，单位统一为 m、s |
| 冲突管理 | 运动冲突矩阵、状态集 | 全部相关冲突车辆对，以及同车道前后车关系 |
| 顺序决策 | 到达估计、进入范围时间、等待时间、承诺状态 | 一致的车辆先后关系，同车道保持 FIFO |
| 名义控制 | 期望速度、前车状态、间距 | 加速度向量，单位 m/s² |
| 安全过滤 | 名义输入、先后关系、状态、输入边界 | 联合加速度、求解状态、活跃约束和残差 |
| 执行与监测 | 控制输入、仿真实际响应 | 实际加速度、冲突占用、干预与失败记录 |

### 决策默认规则

对可参与排序的车道队首，按到首个相关区域的预计到达时间排序；差异不超过 0.1 s 视为平局，依次用进入控制范围的时间和固定车辆 ID 决定。由车道队首逐个建立全局队列，保证 FIFO。等待超过 30 s 的未承诺队首优先于普通候选，多个长期等待候选按等待时间排序。0.1 s 和 30 s 都是待做敏感性检验的策略参数，不是安全常数。

从全局队列导出每一条冲突边的先后关系，而非只检查全局相邻车辆。承诺应在越过最后可安全停止边界之前建立；停车距离需包含控制延迟、模型误差余量及可用制动能力。承诺后的相关先后关系保持到区域清空，不能靠重排改变已经不可撤销的决策。首次承诺与改序都需要检查新安全集合成员资格和输入可行性。

一时刻 QP 有解不能保证以后持续有解；承诺边界、可行域及低速放行条件是里程碑二的理论工作，不能当作已经解决的调度细节。

## 3. 候选控制模型与安全边界

以路径距离和纵向速度建模：\(\dot d_i^m=-v_i\)，\(\dot v_i=u_i\)。控制输入统一为加速度。先使用同一组输入边界和期望速度对照各方法，不同时使用含义不清的“速度输入”与“加速度输入”。

在 \(v_i,v_j>v_{\mathrm{switch}}>0\)、固定顺序及常数 \(\tau_m\) 下：

\[
T_i^m=\frac{d_i^m}{v_i},\quad
h_{ij}^m=T_j^m-T_i^m-\tau_m,\quad
\dot h_{ij}^m=\frac{d_i^m}{v_i^2}u_i-\frac{d_j^m}{v_j^2}u_j.
\]

联合 QP 最小化 \(\sum_i w_i(u_i-u_i^{nom})^2\)，其中 \(w_i>0\)，并同时加入各冲突对的 \(\dot h+\alpha h\ge0\)、加速度边界、速度约束和同车道安全约束。首轮权重相同，不借权重暗中改变安全优先级。名义层负责期望速度与头距跟踪；车队收敛和串稳定性不在本次已有结论之内。

同车道可以研究 \(h_f=g_f-s_0-t_hv_f\)，\(\dot h_f=v_{lead}-v_f-t_hu_f\)。这是需要检查初值和输入可行性的候选约束，而非已经证明的完整跟驰策略。

必须处理的边界：

- **到达时间与碰撞时间不同。** `d/v` 是参考点到达时间估计。文中称 time-to-conflict arrival estimate；碰撞时间需要明确车辆几何和预测轨迹，另行定义。
- **区域占用。** 对先行车辆离开、后行车辆进入，应研究 \(t_{j,in}\ge t_{i,out}+\delta\)。若用常数 \(\tau_m\) 代替，需要推导能覆盖车长、区域宽度和速度范围的占用上界。在区域内允许任意停车时，一般不能假定有限的通用占用上界。
- **低速和停车。** 分母取 `max(v,v_min)` 会引入分段形式，不能继续沿用正速度区间的导数。先设计停止、等待、放行模式与切换条件；在条件尚未明确之前，时间 barrier 只作为局部原型。
- **初始安全和输入可行性。** 前向不变性论证需要适当的模型正则性、安全初值与整个闭环上的可行控制。存在多个约束时，单个约束可行不代表联合可行。
- **无解与备份。** 无解、超时和数值残差超限都记为失败事件。仅在验证过的可停止域中使用停车备份；不得把“最大制动”无条件称为安全策略。安全约束不静默加松弛；若研究松弛版本，单列软约束及违反量。
- **采样与切换。** 连续时间 CBF 条件不自动保证采样间安全。使用更细采样重放、几何占用检查及必要的离散时间论证；换顺序后重新检查新的安全集合。
- **启发式对照。** `-1/h` 在零点奇异，在负值侧符号改变。负修正取 `max` 可能减弱制动；即便取 `min` 或求和，也不能自动保证所有约束成立。任何正则化、饱和处理必须写明为改写版本。

## 5. 对照实验和统计口径

### 对照方法

1. 感应式信号控制：记录相位、清空时间、检测器及最小/最大绿灯参数。若不是原 BaIP 的 FAS 配置，明确称为本研究的感应信号基线。
2. 无信号优先规则：固定道路优先级，同级 FIFO；参数和几何与拟议方法一致。
3. 原始距离 barrier：仅在取得原始定义且场景适用时复现。可先在 figure-eight 上建立参考行为；若缺原始代码/来源，保留该项为待完成，不编造“复现成功”。
4. 拟议排序＋联合 QP：作为主要方法。
5. 消融：固定 FIFO 排序＋同一 QP；拟议排序＋明确正则化的启发式修正。两项分别检验排序和过滤的作用，不混合改变多组参数。

### 初始批量实验建议

- 使用每入口独立泊松到达作为起点，首轮总需求建议 300、600、900 veh/h，均衡分配；不均衡情形以三个入口 60%/20%/20% 分配，并轮换高流量入口。这些数值不预先等同于系统低/中/高饱和度，先通过基线试跑校准后冻结正式实验配置。
- 正式实验使用 20 个配对种子（0–19），各方法读取完全相同的车辆到达时间和路线文件；试调参数使用另一个不交叠种子集合。总仿真 3600 s，前 300 s 单独报告启动瞬态，其后报告稳态窗口。若没有达到稳态，明确报告持续积压，不强称稳态。
- 加入同步到达/突发车流等确定性压力测试。初态可行与不可行实验分开；不可行初态用于失效边界分析，不能混作不变性反例或剔除不报。
- 计算每个种子的指标与方法差，再对种子层面的配对差做 bootstrap 95% 区间（固定重采样种子，10,000 次）。车辆数据不是独立重复试验，不能替代种子层面的不确定性。
- 冻结仿真版本、时间步长、求解器及容差、硬件、控制周期、车辆参数和路网配置。报告运行失败与实际完成种子数。

### 指标

| 类别 | 定义与单位 |
|---|---|
| 物理安全 | 几何接触/重叠事件数、共享区域占用重叠次数、最小车身距离 m；分别报告 |
| 约束表现 | 最小有序时间裕度 s、违反持续时间 s、加速度越界、QP 残差；不把它们直接等同于碰撞 |
| 吞吐量 | 固定观测窗口通过出口的车辆数除以小时数，veh/h；同时报告请求、实际进入与驶离数量 |
| 延误 | 完成时刻减去计划出发时刻，再减同路线自由流时间，s/veh；把插入等待计入。未完成车辆作为右删失队列单列其数量、已等待时间与所在位置 |
| 停车 | 速度低于 0.1 m/s 持续至少 1 s 计一次停车，恢复后再次满足条件算新事件 |
| 舒适性 | 统一采样下加速度 RMS，m/s²；用相邻实际加速度差除以步长计算 jerk RMS，m/s³；先算每车值，再按种子汇总 |
| 活性 | 最大等待时间；存在待通过需求且 60 s 无车辆通过时标记待查死锁，排除已知红灯等待后分析轨迹。该阈值只是筛查规则 |
| 计算和干预 | QP 失败比例、备份次数、求解时间中位数及 P95（ms）、仿真器修改输入/紧急刹车等干预 |
| 可选能耗 | 仅在车辆动力/能耗模型及单位确定后报告 Wh/veh 或相应燃料单位；加速度平方只能称控制代价代理 |

### 仿真可信度

SUMO 的控制指令、跟驰安全逻辑和交叉口优先权设置可能影响最终执行结果。记录命令与实际响应，明确哪些功能由研究控制器负责，哪些由仿真器负责；不得把平台的隐含安全保护算成 barrier 的能力。开启合适的路口碰撞检查，并用独立的路径/车身占用日志辅助验证。移除、瞬移和未插入车辆需要计数，不可从失败样本里消失。

官方接口和配置应按固定的 SUMO 版本核对：[TraCI 车辆状态控制](https://sumo.dlr.de/docs/TraCI/Change_Vehicle_State.html)、[安全与碰撞](https://sumo.dlr.de/docs/Simulation/Safety.html)、[信号灯](https://sumo.dlr.de/docs/Simulation/Traffic_Lights.html)、[TripInfo](https://sumo.dlr.de/docs/Simulation/Output/TripInfo.html)。

## 6. 主要风险与收缩路线

| 风险 | 应对或收缩路线 |
|---|---|
| 到达时间 barrier 不能推出占用安全 | 保留为启发式比较，主方法转向显式区域占用或受限正速度工作域；重新推导而不是加大时间间隔后宣称已证明 |
| 多冲突 QP 经常无解 | 分析可行域、提前协调距离和顺序相容性；先收缩到可证明的场景 |
| 长期等待或锁定导致拥堵 | 保留等待提升规则，测试承诺时机；无环不等于活性保证 |
| 名义控制与安全层互相干扰 | 比较修正大小、激活比例、停车和 jerk；分开调整名义层与安全参数 |
| 计算时间增长 | 记录车辆数/冲突数与求解时间；候选剪枝须检查遗漏风险，之后才研究分布式方法 |
| 创新不足 | 与已有预约/调度＋CBF方法做接口和假设层面的对比，收敛到具体的新性质或失败机制 |
| 前人来源暂缺 | 明确来源状态，先做独立模型与公开基线，不将草稿描述当成原始研究证据 |
